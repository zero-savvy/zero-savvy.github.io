Core Idea

Making sure that images shared online are authentic and trustworthy is a big challenge. But let's be real: most images need some tweaking before they go public. Zero-knowledge proofs (ZKPs) can help by verifying edited images without needing to reveal the original. The problem? ZKPs are often costly, especially when it comes to prover complexity and proof size.

That's where VIMz comes in. VIMz is a framework designed to prove the authenticity of high-resolution images efficiently using folding-based zkSNARKs powered by the Nova proving system. With VIMz, we can verify that both the original and edited images are legit, along with the correctness of the transformations, all without revealing any intermediate versions—only the final image is exposed.

Folding-based zkSNARKs

Leverages the Nova protocol for efficient proof generation with minimal memory footprint

Privacy-Preserving

Protects identities of creators and editors while proving authenticity

Efficient Processing

Row-by-row image commitment scheme enables parallel processing capabilities

High Resolution Support

Handles 8K (33MP) images on mid-range laptops with just 10GB peak memory

Real-World Applications

VIMz enables a new generation of privacy-preserving, trustless applications for image verification and authenticity

Media Authenticity & Deepfake Detection
Verify the authenticity of images and detect manipulated content in an era of sophisticated deepfakes. VIMz provides cryptographic proof that images are genuine or have undergone only declared transformations, helping combat misinformation and restore trust in digital media.
Privacy-Preserving Journalism & Activism
Protect the identity of journalists, NGOs, and freedom fighters while trustlessly authenticating their content anonymously. VIMz enables whistleblowers and activists to prove image authenticity without revealing their identity or location, crucial for those operating in hostile environments.
Trustless, GDPR-Compliant Media Marketplaces
Build decentralized media marketplaces where creators can prove ownership and authenticity of their work without exposing personal information. VIMz enables privacy-preserving verification that complies with GDPR and other data protection regulations while maintaining trust.
Authentic AI Dataset Verification
Ensure the integrity and provenance of training datasets for AI models. VIMz allows dataset curators to prove that images haven't been tampered with or synthetically generated, addressing critical concerns about data quality and bias in machine learning systems.
Privacy-Preserving Liveness & Personhood Proofs
Verify that a person is real and present without revealing their identity or biometric data. VIMz can prove that an image was captured live from a real person while keeping facial features and other identifying information private, useful for anonymous authentication systems.
Content Authenticity for Creative Industries
Enable photographers, artists, and content creators to prove the authenticity of their original work while protecting their creative process. VIMz allows creators to demonstrate that images are unedited originals or to selectively disclose which transformations were applied.

Installation Guide

Get started with VIMz in a few simple steps

Dependencies
Install the required dependencies before setting up VIMz
Node.jsv16.20.0
nvm install v16.20.0
snarkjslatest
npm install -g snarkjs
Ruststable
rustup default stable
Circom2.2.1+
cargo install --path circom
Installing VIMz
Clone and build the VIMz framework
# Clone the repository
git clone https://github.com/zero-savvy/vimz.git
# Navigate to directory
cd vimz
# Build and install
cargo build
cargo install --path .
# Verify installation
vimz --help
Building Circuits
Compile the ZK circuits for image transformations
# Navigate to circuits directory
cd circuits
# Install node modules
npm install
# Build all circuits (or specify individual circuits)
./build_circuits.sh
# Or build specific circuit:
./build_circuits.sh grayscale_step_HD.circom
Running Benchmarks
Test VIMz performance with sample images
# Single transformation benchmark
./benchmark.sh HD contrast
# Multiple transformations (parallel)
./benchmark.sh HD contrast blur sharpness
# 4K resolution benchmark
./benchmark.sh 4K resize
